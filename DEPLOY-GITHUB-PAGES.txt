GitHub Pages deployment instructions

1. Upload ALL files from this archive directly into the root of the repository main branch.
   index.html must be in the repository root.

2. In GitHub open:
   Settings -> Pages

3. Under Build and deployment set:
   Source: GitHub Actions

4. Commit/push the files to main.

5. Open Actions. You should now see the workflow:
   Deploy GitHub Pages

6. Wait until the workflow is green. The site URL is:
   https://kulfoldi-kaszino.github.io/home/

Do NOT choose the Jekyll template. The workflow publishes the existing static HTML directly.
